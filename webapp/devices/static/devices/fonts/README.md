# Bundled fonts

Shipped locally so the controller works on a LAN with no internet.

- **Fraunces** (variable, upright + italic) — Undercase Type, SIL Open Font License 1.1.
  https://github.com/undercasetype/Fraunces
- **Atkinson Hyperlegible Next** (variable, upright + italic) — Braille Institute of America,
  SIL Open Font License 1.1. https://www.brailleinstitute.org/freefont/

Both are the latin-subset woff2 builds served by Google Fonts.
